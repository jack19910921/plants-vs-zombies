# M11 Image2 Asset Replacement Design

## Goal

Replace the current placeholder plant photos and flat board fill with the user-provided ChatGPT image model assets while preserving gameplay logic, grid coordinates, mobile layout, and the existing Phaser rendering path.

## Scope

This slice covers the first M11 pass:

- Add the five user-provided plant images and one garden board image to the repo.
- Convert the five plant images from white/checkerboard RGB backgrounds into cropped transparent PNGs for in-game rendering.
- Use the same plant asset for field plants, bottom cards, locked cards, and cooldown cards.
- Add explicit bottom-center field anchoring in the asset presentation profile.
- Replace the flat board lane fill with a static cropped 3D garden board image while keeping the existing logical `BOARD` rectangle.
- Record all new non-code assets in `docs/asset-sources.md` as AI-generated by OpenAI ChatGPT image model.

This slice does not replace enemies and does not introduce a true 3D engine, GLB assets, or broad gameplay changes.

## Architecture

The existing code already has useful seams, so M11a keeps them:

- `src/game/assets.ts` remains the texture registry.
- `src/game/assetPresentation.ts` owns crop, CSS card framing, field offsets, and field anchor values.
- `src/game/worldPresentation.ts` owns field display sizes and pseudo-3D animation state.
- `src/game/GameScene.ts` consumes those profiles without changing combat or placement rules.
- `src/ui/domOverlay.ts` keeps card artwork wired to the same texture registry.

Plant images use a bottom-center field anchor. The visual transform can bob, squash, stretch, and rotate, but the logical plant lane/column and collision checks stay in `rules.ts`.

## Testing

Automated tests cover:

- New texture registry paths for all M11 assets.
- Bottom-center field anchor values for every plant.
- Card-specific background sizing so large transparent plant art does not break the tray.
- Bounded board crop values for the garden background.

Manual/browser smoke checks cover:

- Game starts with no missing texture errors.
- Bottom cards show the new plant art.
- Field plants sit on the grid without obvious floating.
- The board texture sits behind plants, zombies, projectiles, and UI.

## Risks

The source art uses recognizable plant concepts from the prototype genre, but the user supplied the files for a private family prototype and approved their use. The project still does not import official game assets.

The board artwork perspective does not perfectly match the current logical `BOARD` aspect ratio, so this slice crops the image into the existing board rectangle instead of changing gameplay coordinates.
