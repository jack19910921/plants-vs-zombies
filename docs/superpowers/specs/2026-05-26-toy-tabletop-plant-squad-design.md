# 《玩具桌面植物小队》设计规格

日期：2026-05-26

## 背景

这个项目是一个从零开始的儿童向单机小游戏。目标用户是 6-8 岁的小朋友，喜欢植物和僵尸玩具，希望在电脑上玩一个植物与僵尸对战的小游戏。

游戏不需要联网、不做登录、不做内购、不做广告。第一版优先做网页版，后续保留打包成 Mac 单机应用的空间。

为避免直接复制现有商业素材，第一版使用原创玩具风角色、原创命名和原创视觉资产。玩法可以保留“植物守家、僵尸来袭”的熟悉结构，但角色外观、名称、场景和美术表达都走自己的方向。

## 目标

- 做一个 6-8 岁孩子能独立游玩的 2D 网页小游戏。
- 结合塔防和轻动作：孩子既能种植物布阵，也能控制一个植物英雄救场。
- 单局时间可控，适合家庭使用。
- 难度温和递进，有一点挑战，但失败不挫败。
- 第一版内容完整：5 条路线、5 个可种植物、5 种僵尸、1 个可控植物队长、3 个关卡。
- 技术上先让网页版本跑起来，后续可以用 Tauri 或 Electron 包成 Mac 应用。

## 非目标

- 第一版不做联网、排行榜、账号、存档云同步。
- 第一版不做官方素材导入。
- 第一版不做大型关卡编辑器。
- 第一版不追求复杂物理或 3D 效果。
- 第一版不做复杂剧情，只保留轻量关卡氛围。

## 游戏概念

游戏暂定名为《玩具桌面植物小队》。

场景发生在儿童房的玩具桌面上。桌面上有五条由积木、胶带和彩色轨道组成的路线。僵尸玩具从右侧慢慢走来，想撞倒左侧的玩具基地。小朋友需要种下植物玩具防守，同时控制“豌豆队长”在路线之间移动和射击。

资源不是传统阳光，而是“星星贴纸”。星星贴纸会从空中掉落，也可以由“星星花”生产。小朋友点击星星贴纸收集资源，再用资源种植物。

## 核心玩法

一局游戏由准备、波次进攻、胜利或失败组成。

玩家在五条路线上的格子里种植物。僵尸玩具从右侧沿路线向左移动。植物会自动攻击或阻挡僵尸。玩家同时用键盘控制豌豆队长移动，按空格发射豆豆，补充伤害或救援危险路线。

如果僵尸走到左侧并撞倒玩具基地，当前关卡失败。失败界面使用鼓励式文案，例如“差一点点，再试一次”。如果玩家撑过所有波次，当前关卡胜利，并获得贴纸奖章反馈。

## 操作

- WASD 或方向键：移动豌豆队长。
- 空格：豌豆队长发射豆豆。
- 鼠标点击植物卡片，再点击格子：种植物。
- 鼠标点击掉落的星星贴纸：收集资源。
- ESC 或右上角按钮：暂停。

## 角色

### 可控英雄

豌豆队长是玩家控制的植物英雄。它可以在五条路线之间移动，按空格发射豆豆。它的作用是提高参与感，并让玩家在某条路线快守不住时能够主动救场。

### 可种植物

- 星星花：生产星星贴纸，是经济植物。
- 豆豆炮：基础攻击植物，稳定向右射击。
- 积木坚果：阻挡僵尸，血量高。
- 泡泡蘑菇：短距离减速，让僵尸走慢。
- 弹簧菜：偶尔把近身僵尸弹回一小段。

### 僵尸玩具

- 摇摇僵尸：普通慢速敌人。
- 小桶僵尸：血量更高，移动偏慢。
- 滑板僵尸：移动快，血量低。
- 气球僵尸：优先制造压力，需要玩家或特定攻击处理。
- 大块头玩具僵尸：第三关小 Boss，移动慢但很耐打。

## 关卡

第一版包含三个关卡：

1. 教学关：只教移动、收集星星贴纸、种豆豆炮和基础射击。
2. 普通关：加入积木坚果、泡泡蘑菇和更多路线压力。
3. 小挑战关：加入弹簧菜、滑板僵尸和大块头玩具僵尸，形成完整挑战。

每关都应能在简单和普通难度下完成。默认单局时长为 5 分钟，家长可以设置为 3、5 或 8 分钟。

## 难度

第一版支持简单和普通两档难度。

简单难度适合刚开始玩的孩子：僵尸速度更慢、血量更低、星星贴纸更多。普通难度保留轻度挑战：波次压力更明显，需要搭配植物和控制豌豆队长救场。

难度调节应通过配置控制，避免把参数写死在游戏逻辑里。

## 界面

主菜单包含：

- 开始游戏
- 关卡选择
- 家长设置

游戏内 HUD 包含：

- 植物卡片
- 星星贴纸数量
- 当前波次
- 暂停按钮

关卡结束界面包含：

- 胜利贴纸奖章
- 再玩一次
- 返回关卡选择

失败界面包含：

- 鼓励式文案
- 再试一次
- 返回关卡选择

## UI 设计

第一版需要单独做 UI 设计，而不是只在实现时临时摆按钮。UI 的目标是让 6-8 岁孩子能快速看懂、家长能安心设置，并且不遮挡主要战场。

### 视觉方向

UI 应延续儿童房玩具桌面的风格。按钮和面板可以像贴纸、积木牌、玩具标签，但边缘不要过度圆润到像普通卡通模板。整体应明亮、干净、对比明确。

建议材质语言：

- 植物卡片像玩具包装卡或贴纸卡。
- 星星数量像贴纸收集计数器。
- 关卡按钮像桌面上的积木牌。
- 暂停和设置像小工具盒抽屉。

### 色彩

色彩应避免单一绿色或单一蓝紫。建议使用儿童玩具感的多色 palette：

- 草地和轨道：柔和绿色、浅青色、木桌浅棕。
- 植物 UI：绿色搭配黄色星星、红色提示、蓝色泡泡。
- 僵尸危险提示：橙红色或番茄红，避免恐怖深红。
- 菜单背景：儿童房桌面或玩具盒感，不使用大面积纯渐变。

重要信息需要高对比：星星数量、植物是否可种、路线危险提示必须一眼可见。

### 字体和文字

第一版使用清晰的大号中文字体，优先系统可用的圆润无衬线字体。按钮文字短，避免长句。

建议文案：

- “开始”
- “选关”
- “家长设置”
- “再试一次”
- “暂停”
- “简单”
- “普通”

游戏过程中尽量用图标、数字和短提示，不显示长段说明。教学提示一次只讲一件事，例如“按空格发射豆豆”。

### 游戏内 HUD 布局

正常战斗时要保护战场中心区域。持久 HUD 控制在画面边缘：

- 顶部左侧：星星贴纸数量。
- 顶部中间：波次或剩余进度。
- 顶部右侧：暂停按钮。
- 底部：植物卡片栏。
- 左侧基地附近：必要时显示基地状态。
- 路线危险提示：只在某条路线快被突破时短暂出现。

底部植物卡片栏需要固定高度，不能因为文字或冷却状态改变而跳动。每张卡片需要显示图标、花费和冷却状态。不可种植时变暗，资源足够且冷却结束时高亮。

### 菜单与设置

主菜单不做营销式首页，打开后直接像游戏开始界面：标题、开始、选关、家长设置。背景可以是玩具桌面的静态场景或轻微动效。

家长设置应简短：

- 难度：简单 / 普通，使用分段按钮。
- 时长：3 / 5 / 8 分钟，使用分段按钮。
- 音量：开关或简单滑块。

设置页不应混入复杂说明，也不应让孩子误触危险操作。返回按钮始终清楚。

### 反馈和动效

动效应该服务于状态变化：

- 收集星星贴纸时，星星飞向计数器。
- 成功种植物时，格子轻微弹一下。
- 植物卡片冷却结束时，卡片轻亮一下。
- 路线危险时，轨道边缘短暂闪烁。
- 胜利时出现贴纸奖章。

避免所有按钮一直抖动、发光或循环动画。重要动效要尊重系统的减少动态效果设置，非必要动画可以关闭或减弱。

### 响应式范围

第一版主目标是电脑键盘鼠标，所以优先适配桌面浏览器。画面建议按 16:9 设计，并在常见桌面尺寸中居中缩放。窗口变小时，植物卡片栏和文字应缩放或换行，不能重叠。

移动端不是第一版目标，但布局不要完全依赖固定像素。后续如果做触屏版，可以把移动、攻击和种植改成大按钮与点按操作。

### UI 实现边界

游戏世界、角色、投射物、轨道和战斗反馈由 Phaser 渲染。文本较多、需要清晰布局和可访问性的 UI，例如主菜单、家长设置、暂停菜单、关卡结束界面，可以使用 DOM 覆盖层实现。

高频战斗 HUD 可以根据实现复杂度选择 Phaser 或 DOM，但必须保持一个明确的状态来源，避免 UI 和游戏状态不同步。

## 家长设置

第一版提供轻量家长设置：

- 难度：简单 / 普通。
- 单局时长：3 / 5 / 8 分钟。
- 音量：开 / 关，或简单滑块。

无失败模式可以在代码结构中预留，但不作为第一版默认功能。

## 视觉风格

整体视觉是原创玩具风。角色看起来像小朋友桌面上的塑料玩具、积木玩具或贴纸玩具。画面应圆润、明亮、清楚，不做恐怖表现。

场景是儿童房玩具桌面。五条路线可以是积木轨道、胶带轨道或彩色纸条。资源是星星贴纸。胜利奖励也以贴纸、小奖章、玩具盒反馈为主。

第一版可以使用简单矢量图形和清晰轮廓作为原创初版美术。后续可以替换为更精致的贴图，或扩展为用户家里玩具照片处理后的版本。

## 技术方案

第一版使用 Phaser + Vite + TypeScript。

Phaser 负责：

- 游戏场景
- 角色对象
- 轨道和格子
- 碰撞和命中
- 波次生成
- 动画和音效
- 菜单、暂停、设置等游戏内 UI

Vite 负责：

- 本地开发服务器
- 快速构建
- 静态网页输出

TypeScript 负责：

- 游戏对象类型
- 植物、僵尸、关卡和难度配置
- 更稳定的重构和后续扩展

第一版采用 Phaser + DOM 的混合 UI 边界。Phaser 负责游戏世界和高频战斗对象，DOM 负责主菜单、家长设置、暂停、关卡结束等文字和布局较多的界面。实现时需要把 UI 状态集中管理，避免 Phaser 状态和 DOM 状态分叉。

## 数据设计

植物、僵尸、关卡、波次和难度参数都应配置化。

建议配置包括：

- 植物：名称、花费、冷却、血量、攻击力、攻击间隔、射程、特殊效果。
- 僵尸：名称、血量、速度、伤害、奖励、特殊能力。
- 关卡：可用植物、敌人种类、波次数、教程提示、背景主题。
- 难度：僵尸血量倍率、僵尸速度倍率、资源掉落倍率、波次间隔。
- 时长：3 / 5 / 8 分钟对应的波次数和节奏。

## 错误和边界处理

- 星星贴纸数量不能变成负数。
- 植物卡片冷却时不能重复种植。
- 已有植物的格子不能重复种植，除非后续设计铲除功能。
- 僵尸死亡、到达基地、被弹回时都必须从活动列表中正确移除或更新。
- 暂停时角色、投射物、波次计时和资源掉落都应暂停。
- 关卡结束后不能继续生成新敌人或处理新的种植输入。

## 测试和验证

第一版完成时需要验证：

- 三个关卡都能从开始玩到胜利或失败。
- 简单和普通难度都能正常运行。
- 3 / 5 / 8 分钟设置能改变关卡节奏。
- WASD、方向键、空格和鼠标点击都能工作。
- 星星贴纸资源不会出现负数。
- 植物卡片冷却和花费正常。
- 僵尸波次能正常开始和结束。
- 暂停和恢复不会破坏游戏状态。
- 桌面浏览器里画面不重叠，文字不溢出。
- 游戏没有联网依赖，构建后可以本地打开或静态托管。

## 后续扩展

第一版之后可以考虑：

- 打包成 Mac 单机应用。
- 增加无失败模式。
- 增加更多植物玩具和僵尸玩具。
- 增加贴纸收藏册。
- 使用用户家里的玩具照片制作特殊皮肤。
- 增加更多儿童房场景，例如地毯、书桌、积木城堡。
- 增加家长可调的自动攻击或辅助瞄准强度。
