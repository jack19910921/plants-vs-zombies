# 《玩具桌面植物小队》设计规格

日期：2026-05-26

## 背景

这个项目是一个从零开始的儿童向单机小游戏。目标用户是 6-8 岁的小朋友，喜欢植物和僵尸玩具，希望在电脑上玩一个植物与僵尸对战的小游戏。

游戏不需要联网、不做登录、不做内购、不做广告。第一版优先做网页版，后续保留打包成 Mac 单机应用的空间。

为避免直接复制现有商业素材，第一版使用原创玩具风角色、原创命名和原创视觉资产。玩法可以保留“植物守家、僵尸来袭”的熟悉结构，但角色外观、名称、场景和美术表达都走自己的方向。

## 目标

- 做一个 6-8 岁孩子能独立游玩的 2D 网页小游戏。
- 结合塔防和轻动作：孩子既能种植物布阵，也能控制一个植物英雄救场。
- 单局时间可控，适合家庭使用。
- 难度温和递进，有一点挑战，但失败不挫败。
- 第一版内容完整：5 条路线、5 个可种植物、5 种僵尸、1 个可控植物队长、3 个关卡。
- 技术上先让网页版本跑起来，后续可以用 Tauri 或 Electron 包成 Mac 应用。

## 非目标

- 第一版不做联网、排行榜、账号、存档云同步。
- 第一版不做官方素材导入。
- 第一版不做大型关卡编辑器。
- 第一版不追求复杂物理或 3D 效果。
- 第一版不做复杂剧情，只保留轻量关卡氛围。

## 游戏概念

游戏暂定名为《玩具桌面植物小队》。

场景发生在儿童房的玩具桌面上。桌面上有五条由积木、胶带和彩色轨道组成的路线。僵尸玩具从右侧慢慢走来，想撞倒左侧的玩具基地。小朋友需要种下植物玩具防守，同时控制“豌豆队长”在路线之间移动和射击。

资源不是传统阳光，而是“星星贴纸”。星星贴纸会从空中掉落，也可以由“星星花”生产。小朋友点击星星贴纸收集资源，再用资源种植物。

## 核心玩法

一局游戏由准备、波次进攻、胜利或失败组成。

玩家在五条路线上的格子里种植物。僵尸玩具从右侧沿路线向左移动。植物会自动攻击或阻挡僵尸。玩家同时用键盘控制豌豆队长移动，按空格发射豆豆，补充伤害或救援危险路线。

如果僵尸走到左侧并撞倒玩具基地，当前关卡失败。失败界面使用鼓励式文案，例如“差一点点，再试一次”。如果玩家撑过所有波次，当前关卡胜利，并获得贴纸奖章反馈。

## 操作

- WASD 或方向键：移动豌豆队长。
- 空格：豌豆队长发射豆豆。
- 鼠标点击植物卡片，再点击格子：种植物。
- 鼠标点击掉落的星星贴纸：收集资源。
- ESC 或右上角按钮：暂停。

## 角色

### 可控英雄

豌豆队长是玩家控制的植物英雄。它可以在五条路线之间移动，按空格发射豆豆。它的作用是提高参与感，并让玩家在某条路线快守不住时能够主动救场。

### 可种植物

- 星星花：生产星星贴纸，是经济植物。
- 豆豆炮：基础攻击植物，稳定向右射击。
- 积木坚果：阻挡僵尸，血量高。
- 泡泡蘑菇：短距离减速，让僵尸走慢。
- 弹簧菜：偶尔把近身僵尸弹回一小段。

### 僵尸玩具

- 摇摇僵尸：普通慢速敌人。
- 小桶僵尸：血量更高，移动偏慢。
- 滑板僵尸：移动快，血量低。
- 气球僵尸：优先制造压力，需要玩家或特定攻击处理。
- 大块头玩具僵尸：第三关小 Boss，移动慢但很耐打。

## 关卡

第一版包含三个关卡：

1. 教学关：只教移动、收集星星贴纸、种豆豆炮和基础射击。
2. 普通关：加入积木坚果、泡泡蘑菇和更多路线压力。
3. 小挑战关：加入弹簧菜、滑板僵尸和大块头玩具僵尸，形成完整挑战。

每关都应能在简单和普通难度下完成。默认单局时长为 5 分钟，家长可以设置为 3、5 或 8 分钟。

## 难度

第一版支持简单和普通两档难度。

简单难度适合刚开始玩的孩子：僵尸速度更慢、血量更低、星星贴纸更多。普通难度保留轻度挑战：波次压力更明显，需要搭配植物和控制豌豆队长救场。

难度调节应通过配置控制，避免把参数写死在游戏逻辑里。

## 界面

主菜单包含：

- 开始游戏
- 关卡选择
- 家长设置

游戏内 HUD 包含：

- 植物卡片
- 星星贴纸数量
- 当前波次
- 暂停按钮

关卡结束界面包含：

- 胜利贴纸奖章
- 再玩一次
- 返回关卡选择

失败界面包含：

- 鼓励式文案
- 再试一次
- 返回关卡选择

## 家长设置

第一版提供轻量家长设置：

- 难度：简单 / 普通。
- 单局时长：3 / 5 / 8 分钟。
- 音量：开 / 关，或简单滑块。

无失败模式可以在代码结构中预留，但不作为第一版默认功能。

## 视觉风格

整体视觉是原创玩具风。角色看起来像小朋友桌面上的塑料玩具、积木玩具或贴纸玩具。画面应圆润、明亮、清楚，不做恐怖表现。

场景是儿童房玩具桌面。五条路线可以是积木轨道、胶带轨道或彩色纸条。资源是星星贴纸。胜利奖励也以贴纸、小奖章、玩具盒反馈为主。

第一版可以使用简单矢量图形和清晰轮廓作为原创初版美术。后续可以替换为更精致的贴图，或扩展为用户家里玩具照片处理后的版本。

## 技术方案

第一版使用 Phaser + Vite + TypeScript。

Phaser 负责：

- 游戏场景
- 角色对象
- 轨道和格子
- 碰撞和命中
- 波次生成
- 动画和音效
- 菜单、暂停、设置等游戏内 UI

Vite 负责：

- 本地开发服务器
- 快速构建
- 静态网页输出

TypeScript 负责：

- 游戏对象类型
- 植物、僵尸、关卡和难度配置
- 更稳定的重构和后续扩展

第一版 UI 可以主要放在 Phaser 画布内，减少 DOM 和游戏状态之间的同步复杂度。后续如果菜单复杂化，再考虑 DOM 覆盖层。

## 数据设计

植物、僵尸、关卡、波次和难度参数都应配置化。

建议配置包括：

- 植物：名称、花费、冷却、血量、攻击力、攻击间隔、射程、特殊效果。
- 僵尸：名称、血量、速度、伤害、奖励、特殊能力。
- 关卡：可用植物、敌人种类、波次数、教程提示、背景主题。
- 难度：僵尸血量倍率、僵尸速度倍率、资源掉落倍率、波次间隔。
- 时长：3 / 5 / 8 分钟对应的波次数和节奏。

## 错误和边界处理

- 星星贴纸数量不能变成负数。
- 植物卡片冷却时不能重复种植。
- 已有植物的格子不能重复种植，除非后续设计铲除功能。
- 僵尸死亡、到达基地、被弹回时都必须从活动列表中正确移除或更新。
- 暂停时角色、投射物、波次计时和资源掉落都应暂停。
- 关卡结束后不能继续生成新敌人或处理新的种植输入。

## 测试和验证

第一版完成时需要验证：

- 三个关卡都能从开始玩到胜利或失败。
- 简单和普通难度都能正常运行。
- 3 / 5 / 8 分钟设置能改变关卡节奏。
- WASD、方向键、空格和鼠标点击都能工作。
- 星星贴纸资源不会出现负数。
- 植物卡片冷却和花费正常。
- 僵尸波次能正常开始和结束。
- 暂停和恢复不会破坏游戏状态。
- 桌面浏览器里画面不重叠，文字不溢出。
- 游戏没有联网依赖，构建后可以本地打开或静态托管。

## 后续扩展

第一版之后可以考虑：

- 打包成 Mac 单机应用。
- 增加无失败模式。
- 增加更多植物玩具和僵尸玩具。
- 增加贴纸收藏册。
- 使用用户家里的玩具照片制作特殊皮肤。
- 增加更多儿童房场景，例如地毯、书桌、积木城堡。
- 增加家长可调的自动攻击或辅助瞄准强度。
