# External Asset Sources

This prototype intentionally avoids official Plants vs. Zombies assets. The current local textures come from public-domain or CC0-style sources and are committed so the game runs offline.

M5 visual normalization uses only the local files listed below. Crop, contrast, saturation, framing, silhouette, and wear effects are implemented in code; no additional external assets were added for the M5 closeout.

## M11 Image2 Asset Replacement

The M11 replacement assets below were provided by the user for this private prototype. Plant files were locally processed from the original RGB PNGs into cropped transparent PNGs so the Phaser field and bottom cards can render them without white or checkerboard backgrounds, then downscaled to a maximum 640px edge for runtime weight. The garden board is copied as a static RGB background texture and downscaled to 1280x720. The follow-up 007-014 image2 files were processed the same way for the screenshot cleanup pass, replacing fake-looking enemies, projectiles, sun tokens, base signage, and the left-top toy tool prop. The toy enemy SVG files are original in-repository vector assets created for this private prototype and kept as superseded local source history.
